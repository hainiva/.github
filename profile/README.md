## Open-source SDKs

Every package is MIT-licensed and published to npm from these repos with provenance.

| Package | What it does |
| --- | --- |
| [`@hainiva/app-sdk`](https://github.com/hainiva/app-sdk) | Let the users of your mobile or web app chat and call your HAINIVA contact center from inside your app. |
| [`@hainiva/agent-sdk`](https://github.com/hainiva/agent-sdk) | Build your own staff app on HAINIVA: sign-in through your backend, live event stream, call handling, LiveKit audio for web and React Native. |
| [`@hainiva/react-native-call`](https://github.com/hainiva/react-native-call) | Native incoming calls for agent apps on React Native / Expo: Android lock-screen call notifications, iPhone PushKit + CallKit. |

**Two ways to integrate:** directly with your own organisation's API key, or indirectly through a HAINIVA partner that manages several organisations. Both use the same API. See the [overview](https://hainiva.com/en/developers/docs/overview).
